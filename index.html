      06 — How I work
      
My QA process, end to end

      
The same loop whether it's a two-week MVP sprint or an enterprise ERP release.

    


    
    
      
  1. 01
    Requirement Analysis
    Read the spec like an adversary. Ambiguities, missing acceptance criteria and edge cases get raised before a line of code is written.
    2. 
      
  2. 02
    Test Planning & Strategy
    Scope, entry/exit criteria, environments, risk-based priorities and the requirement traceability matrix — so coverage is provable, not assumed.
    3. 
      
  3. 03
    Test Design
    Scenarios and cases using black-box techniques: equivalence partitioning, boundary values, decision tables, state transition and error guessing.
    4. 
      
  4. 04
    Execution & Automation
    Manual passes for new behaviour, automated Playwright/Selenium suites for regression, Postman/Newman for the API layer, JMeter for load.
    5. 
      
  5. 05
    Defect Management
    Clear reproduction steps, severity and priority, evidence attached, tracked in Jira through the full defect life cycle until verified closed.
    6. 
      
  6. 06
    Reporting & Sign-off
    Test summary reports, coverage and defect metrics, and an honest go/no-go recommendation stakeholders can actually act on.
